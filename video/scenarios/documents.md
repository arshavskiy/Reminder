# מסמכים — רשימה ומידע שחולץ

משך יעד: 35 שניות.

1. פותחים את מסמכים ומראים את שלוש הלשוניות: מסמכים, תסקירים, הצעות מחיר.
2. מציגים שורות שבהן מופיעים שם הקובץ, סטטוס, לקוח, תאריך ומספר תסקיר.
3. מסננים לפי לקוח ואז מחזירים את כל הרשומות.
4. פותחים מסמך שחולץ כדי לעבור למסך הפרטים.

תוצאת הסיום: הנתונים שחולצו מוצגים כבר ברשימה ולא נשארים רק בקובץ המקור.
