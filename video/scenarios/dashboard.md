# דשבורד — העלאה, OCR/AI ולוח שנה

משך יעד: 45–60 שניות.

1. פותחים את הדשבורד ומציגים את אזור **„גרור מסמכים לתזכורת כאן”**.
2. לוחצים על האזור ובוחרים את כל 20 קובצי ה-PDF מתוך `output/pdf/demo-upload-files`.
3. מציגים את חלון **תוצאות העלאה** בזמן שהקבצים עוברים OCR וחילוץ AI.
4. ממתינים עד שכל השורות מסומנות **הושלם**; מציגים לפחות שורת הצעת מחיר עם לקוח, אימייל ותאריך שחולצו.
5. לוחצים **עבור למסמכים** ומציגים את הרשימה המעודכנת.
6. חוזרים לדשבורד, פותחים את חודש אוקטובר 2026 ומציגים את התזכורות שנוצרו.

תוצאת הסיום: 20 מסמכים, לקוחות שנוצרו מהחילוץ ונתונים מוכנים לעבודה.
