# דשבורד — העלאה, OCR/AI ולוח שנה

משך יעד: 45–60 שניות.

1. פותחים את הדשבורד ומציגים את אזור **„גרור מסמכים לתזכורת כאן”**.
2. לוחצים על האזור ובוחרים את עשרת קובצי ה-PDF מתוך `video/assets/demo-upload-files-hebrew`.
3. מציגים את חלון **תוצאות העלאה** בזמן שהקבצים עוברים OCR וחילוץ טבלאות ציוד.
4. ממתינים עד שכל השורות מסומנות **הושלם**; מציגים שורה עם לקוח, מספר תסקיר ותאריך שחולצו.
5. לוחצים **עבור למסמכים** ומציגים את הרשימה המעודכנת.
6. חוזרים לדשבורד, פותחים את חודש אוקטובר 2026 ומציגים את התזכורות שנוצרו.

תוצאת הסיום: מסמכי ההדגמה, לקוחות שנוצרו מהחילוץ ונתונים מוכנים לעבודה.
