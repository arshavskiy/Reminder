# תסריטי וידאו למוצר

כל קובץ מתאר הקלטה עצמאית למסך אחד. לפני כל הקלטה משתמשים בחשבון דמו נקי, בנתוני הדגמה עקביים ובמצב RTL. המסכים אינם כוללים כתובות אימייל או קישורי כניסה אמיתיים.

## תנאי איכות

- מתחילים בכותרת המסך ובערך העסקי שלו.
- מראים פעולה אחת מלאה ותוצאתה, ולא רק מעבר בין מסכים.
- בהעלאת מסמכים מחכים לסטטוס `הושלם` ולנתונים שחולצו לפני מעבר לרשימה.
- משתמשים במסמכי ההדגמה ובנתוני ה-OCR הקיימים בחשבון הווידאו.

## קבצים

- `full-product-demo.md` — תהליך מלא: העלאה, OCR, תסקירים, לקוחות, תזכורת, יומן, הצעת מחיר ודוח חודשי.
- `dashboard.md` — העלאה מדשבורד, OCR/AI ולוח שנה.
- `documents.md` — רשימה, סינון ומידע שחולץ.
- `document-detail.md` — מסמך בודד ונתונים שחולצו.
- `inspections.md` — תסקיר רב-מכשירי.
- `quotes.md` — הצעת מחיר וסעיפי שירות.
- `quote-detail.md` — הצעת מחיר בודדת, סעיפים ותצוגת PDF.
- `clients.md` — לקוחות ופרטי קשר.
- `client-detail.md` — כרטיס לקוח עם תסקירים, ציוד ותזכורות.
- `reminders.md` — תזכורות ומעקב.
- `reports.md` — דוח שנתי ושליחה במייל.
- `profile-settings.md` — פרופיל, לוגו, חתימה והגדרות.
- `equipment.md` — ציוד והיסטוריית בדיקות.
- `templates.md` — תבניות מסמכים, PDF ומייל.
- `search.md` — חיפוש בין מסמכים ולקוחות.
